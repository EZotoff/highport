=== Files Modified ===
1. apps/web/components/chargen/steps/TermResolutionStep.tsx
   - handleGenerateMishapDescription: added Yjs persistence of AIProvenance

     pendingReviewBy: null, status: 'accepted', textarea shows description.

=== Root Cause ===
handleGenerateMishapDescription only set local React state but never persisted
the provenance to the Yjs term. When renderSurvival() read currentTerm.mishapDescription,
it was undefined, causing shouldShowDraft (which treats undefined provenance as visible)
to leak the AI draft to non-GM players in strict mode.

=== Fix ===
Added the same Yjs persistence pattern used by handleGenerateDescription:
getYDoc() → clone terms → create AIProvenance → update term → updateCharacterFields.
